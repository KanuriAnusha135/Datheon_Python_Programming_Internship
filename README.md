# Datheon Python Programming Internship

This repository contains my Python projects completed as part of the Datheon Python Programming Internship.

## Tasks Completed

### Task 1 – Hangman Game

A word-guessing game where users guess a hidden word within six incorrect attempts.

**Technologies:** Python, Random module

### Task 2 – Automated File Organizer

A Python program that automatically organizes files into folders based on their extensions.

**Technologies:** Python, OS module, Shutil module

### Task 3 – Rule-Based Chatbot

A simple terminal-based chatbot that responds to predefined user messages.

**Technologies:** Python, Conditional Statements, While Loop

## How to Run

Open the respective task folder in the terminal and execute:

```bash
python hangman.py
python organizer.py
python chatbot.py
```
